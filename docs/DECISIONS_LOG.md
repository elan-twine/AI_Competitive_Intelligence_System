## 2026-08-05 — News attribution was silently broken since Jul 20 (schema mismatch) — parse node FIXED

- **Found while auditing OpenAI spend** (Dustin asked why News is 88% of it): the News flow ran "successfully" every day, called gpt-4.1 ~44×/run, and **persisted nothing** — no article published after **2026-07-20** has a `companyName` or `post_weight`.
- **Root cause:** the 2026-07-23 multi-company refactor changed the attribution gate's output to `{url, companies:[{companyName,sentiment,reasoning}]}`, but the News branch downstream still read FLAT `$json.companyName` → always undefined → `Parse News Credibility` emitted 0 items → `Compute/Write News post_weight` never executed. Compounded by the prompt's "[] if none": no-match articles return a bare `[]` carrying no url, so they couldn't be paired back to an article either.
- **Fix (published, node `Parse News LLM` only):** pairs each response to its source article (pairedItem, positional fallback), flattens `companies[]` → flat `companyName` + `company_names[]` + sentiment/reasoning, emits `NONE` for genuine no-match, and distinguishes an unparseable reply (`attribution_ok:false`) from a clean NONE. Prefilter prompt-caching restructure from earlier the same day left intact.
- **Impact:** News carries the 15× multiplier — the heaviest platform. ~2 weeks of news mentions missing from every competitor's SOV.
- ⚠️ **Backfill pending Elan's go:** 1,367 scraped-but-unattributed rows — **701 since Jul 20 (this outage)** and **666 from Jun 26–Jul 20** (older gap; some are likely legitimately-irrelevant articles, since a NONE verdict is currently never written back — the gate's false branch drops them). Est. $19 via gpt-4.1, ~$4 via mini.
- **Known design gap (not fixed):** NONE verdicts still aren't persisted, so "checked and irrelevant" is indistinguishable from "never checked". Worth a follow-up write node.
